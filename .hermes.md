# SpotSeparator

**Spot color separation tool** — separates a PDF's spot color channels into individual PDF files (one per spot color). Used for OPW (Opaque White) plate prep and press proofing.

**Live:** https://4003player.github.io/SpotSeparator/  
**Repo:** https://github.com/4003player/SpotSeparator.git  
**Stack:** Single-file `index.html` (~390 lines), no build step, GH Pages hosted.

## Architecture

- Uses a **GitHub-hosted serverless function** (`ghFetch`) for the actual PDF separation work
- The frontend is a lightweight upload/download UI
- Spot color detection via `/Separation` and `/DeviceN` color space parsing

## Key Functions

- `addFiles()` / `removeFile()` / `renderFiles()` — file management UI
- `startSeparation()` — kicks off the separation job
- `ghFetch()` — calls the backend separation service
- `showStatus()` / `clearStatus()` — progress reporting

## What It Does

1. User uploads one or more PDFs
2. Tool detects all spot colors in each PDF
3. Generates individual PDF files — one per spot color channel
4. User downloads the separated plates

## Critical Rules

1. CutContour is a spot color — handled alongside other separations
2. Same Apple light theme as all WAC tools
